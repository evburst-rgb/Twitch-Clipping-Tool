Installer Setup Guide

Follow these steps to install the app, launch the dashboard, connect Twitch, configure your trigger URL, choose a hotkey, and start creating clips.

The app now uses a Windows installer. You no longer need to manually extract a ZIP folder. Install it, launch it, login with Twitch, and connect the tray app with your private Trigger URL.

Install & First Launch

1

Download the Installer

Download the latest EvBurst Clipping Tool Setup file from the official GitHub Release. The installer file will look similar to:

EvBurst Clipping Tool Setup.exe
Windows may show a SmartScreen warning because this beta app is new and unsigned. If you downloaded it from the official GitHub Release, choose More Info then Run Anyway.
2

Run the Installer

Open the setup file and follow the installer steps. You can choose whether to create a desktop shortcut during installation.

The installer adds the app, required guide files, Start Menu shortcuts, and an uninstaller.
3

Launch the App

After installation, launch EvBurst Clipping Tool. The app opens the dashboard automatically and also runs in the Windows system tray near the clock.

If you do not see the tray icon, check the hidden icons arrow near the Windows clock.
4

Login with Twitch

On the dashboard, click Login with Twitch and approve the requested permissions. These permissions allow the app to create clips and post clip links to your Twitch chat.

Connect the Tray App

5

Copy Your Trigger URL

After logging in, copy your private Stream Deck Trigger URL from the dashboard. This URL connects the tray app, hotkeys, and Stream Deck triggers to your Twitch account.

Do not share your Trigger URL. Treat it like a private key for your clipping tool.
6

Set Trigger URL

Right-click the EvBurst tray icon and choose Set Trigger URL. Paste your copied Trigger URL into the prompt and save it.

This only needs to be done once unless you reinstall, clear your app settings, or reset your trigger URL.

Choose How You Want to Clip

7

Keyboard Hotkey

On the dashboard, choose your preferred one-press hotkey and click Save Hotkey.

  • F8
  • F9
  • F10
The tray app must be running for keyboard hotkeys to work.
8

Stream Deck

To use Stream Deck, add a Website action in the Stream Deck app and paste your private Trigger URL into that action.

Stream Deck is optional. You can use hotkeys or the tray menu instead.
9

Tray Menu

You can also right-click the tray icon and choose Trigger Clip Now. This creates a clip without needing a Stream Deck button.

10

Run at Startup

Right-click the tray icon and enable Run at Windows Startup if you want the clipping tool to start automatically when Windows starts.

Create & Find Your Clips

11

Go Live on Twitch

Your Twitch channel must be live before creating clips. Twitch will not create a new clip while the channel is offline.

12

Create a Clip

While live, trigger a clip using your saved hotkey, Stream Deck button, dashboard button, or the tray menu.

Hotkey Press F8, F9, or F10 while live.
Stream Deck Press your configured Stream Deck button.
Tray Menu Select Trigger Clip Now from the tray icon.
13

View Recent Clips

Created clips appear on the dashboard under Recent Clips with title, thumbnail, chat post status, and an open clip button.

14

Find Downloaded Clips

Clips created through the tray app are automatically downloaded to:

Videos\Stream Clips
You can also right-click the tray icon and choose Open Clip Folder.

Installed App Locations

15

Start Menu

After installation, the app can be launched from the Windows Start Menu by searching:

EvBurst Clipping Tool

Depending on the installer version, you may also see an uninstall shortcut in the Start Menu folder.

16

Uninstall

To remove the app, open Windows Settings and go to:

Settings → Apps → Installed Apps → EvBurst Clipping Tool → Uninstall

Features Included

  • Windows installer support
  • Dashboard opens automatically on launch
  • One-button Stream Deck clipping
  • One-press keyboard hotkey clipping
  • Automatic Twitch chat posting
  • Automatic MP4 clip downloads
  • Recent Clips dashboard
  • Clip thumbnails and titles
  • Tray app with Open Dashboard and Open Clip Folder
  • Run at Windows Startup option

Important Notes

Your Twitch channel must be live for clip creation to work. If you are offline, Twitch will not create a new clip.

Keep your Trigger URL private. Treat it like a private key for your channel.

Dashboard/backend updates happen automatically through the hosted web app. Installer or EXE updates require downloading the newest GitHub Release.
