EVBURST
CLIPPING TOOL

EvBurst Clipping Tool is a creator utility built for Twitch streamers who want fast clip creation, Stream Deck support, keyboard hotkeys, automatic downloads, Twitch chat posting, and a clean dashboard for managing recent clips.

Main Features

  • One-button Twitch clip creation
  • Stream Deck trigger support
  • Keyboard hotkey support
  • Automatic clip downloads
  • Twitch chat auto-posting
  • Recent Clips History
  • Clip thumbnails and titles
  • Windows tray app support
  • Cloud-hosted dashboard
  • Twitch token auto-refresh

Hotkey Support

Users can trigger clips with a one-press keyboard hotkey while the tray app is running. The current supported hotkey options are:

F8 Optional one-press clipping key.
F9 Optional one-press clipping key.
F10 Default recommended clipping key.
Synced from Dashboard The tray app checks the saved dashboard hotkey and uses that key for clipping.

Stream Deck Support

Each user receives a private Stream Deck Trigger URL from the dashboard. This URL can be added to a Stream Deck Website action to create clips instantly while live.

The Stream Deck Trigger URL should be treated like a private key and should not be shared.

Auto Downloads

When a clip is created through the tray app, the app downloads the created Twitch clip as an MP4 file. Clips are saved to:

Videos\Stream Clips

Users can also right-click the tray icon and select Open Clip Folder to quickly access downloaded clips.

Dashboard Overview

The dashboard gives users a central place to login with Twitch, view live/offline status, copy their private Stream Deck Trigger URL, select their hotkey, and view recent clips.

The app now opens the dashboard automatically when launched so users know the app is running.

Recent Clips History

Recent clips are saved to the user dashboard with clip title, thumbnail, chat posting status, and an open clip button.

Recent Clips History is designed to help creators quickly review and access clips created during a stream.

Tray App Behavior

The Windows tray app runs in the background and powers hotkey clipping, Stream Deck trigger syncing, clip downloads, startup behavior, and quick access controls.

Open Dashboard Launches the web dashboard in the browser.
Set Trigger URL Saves the user's private trigger URL into the tray app.
Trigger Clip Now Creates a clip directly from the tray menu.
Open Clip Folder Opens the folder where downloaded clips are stored.
Run at Windows Startup Allows the tray app to start automatically with Windows.
Quit Fully closes the tray app.

Supported Systems

  • Windows 10
  • Windows 11
  • Twitch account required
  • Internet connection required
  • Stream Deck optional
  • Keyboard hotkeys supported through the Windows tray app

Beta Disclaimer

This app is currently in beta. Some users may see a Windows SmartScreen warning because the app is new and unsigned. Only download the app from the official EvBurst GitHub Release.

Twitch channels must be live for new clips to be created. If the channel is offline, Twitch will not generate a clip.

Dashboard updates are delivered through the hosted web app. EXE updates require downloading the latest release version.
