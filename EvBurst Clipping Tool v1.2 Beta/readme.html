Welcome

Thank you for downloading the EvBurst Clipping Tool. This app helps Twitch creators instantly create clips, trigger clips from Stream Deck or a keyboard hotkey, automatically post clips into Twitch chat, save clip history to the dashboard, and download created clips directly to your computer.

Quick Setup

  1. Launch EvBurst Clipping Tool.exe
  2. Right-click the tray icon near your Windows clock
  3. Choose Open Dashboard
  4. Login with your Twitch account
  5. Authorize the requested Twitch permissions
  6. Copy your private Stream Deck Trigger URL from the dashboard
  7. Right-click the tray icon again and choose Set Trigger URL
  8. Paste your Trigger URL into the tray app prompt
  9. Choose your preferred hotkey on the dashboard: F8, F9, or F10
  10. Go live on Twitch
  11. Press your saved hotkey, use your Stream Deck button, or choose Trigger Clip Now from the tray menu

Stream Deck Setup

  1. Open the Stream Deck app
  2. Add a Website action
  3. Paste your private Trigger URL from the EvBurst dashboard
  4. Save the button
  5. Press the Stream Deck button while live to create a clip instantly

Keyboard Hotkey Setup

The Windows tray app supports one-press clipping using preset hotkeys. Available options are:

  • F8
  • F9
  • F10

The tray app must be running in the background for keyboard hotkeys to work. You can enable Run at Windows Startup from the tray menu.

Clip Downloads

Created clips are automatically downloaded to your own PC after they are created. Clips are saved locally in:

Videos\Stream Clips

You can also right-click the tray icon and choose Open Clip Folder to quickly access your downloaded clips.

Features

  • One-button Stream Deck clipping
  • Keyboard hotkey clipping
  • Automatic Twitch chat posting
  • Automatic local clip downloads
  • Recent clip dashboard
  • Clip thumbnails and titles
  • Persistent clip history
  • Cloud hosted backend
  • Twitch token auto-refresh
  • Windows tray app support

Important

Your Twitch channel MUST be live for clipping to work.

Do not share your Stream Deck Trigger URL with anyone. Your Trigger URL functions like a private clip key.

Local clip downloading is handled by the Windows tray app. If the tray app is closed, clips may still be created through the dashboard or Stream Deck, but local downloads and keyboard hotkeys will not run.
